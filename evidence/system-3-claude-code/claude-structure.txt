.claude/skills/deploy-check/SKILL.md
  name: deploy-check
  description: Deployment readiness validation skill
  type: forked-context
  context: fork
  read-only: true
  allowed-tools:
    - view (read file contents)
    - grep (search file contents)
    - bash (execute safe shell commands)
  denied-tools:
    - edit (prevent infrastructure changes)
    - create (prevent new infrastructure)
    - git (prevent version control)
  fork-reason: "Isolate deployment validation in separate context to prevent accidental changes"
  fork-scope: infrastructure
  fork-state: "Load only deployment-related files and terraform state"

  3. Test rule (backend/CLAUDE.md::python-test): Override for test_*.py files
  Precedence: most-specific (test_*.py) > more-specific (*.py) > general (root)
